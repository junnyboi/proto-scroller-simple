## Execution sequence and ownership

1. **Stage and run contracts:** `scripts/stages/`, `resources/stages/`, `scripts/main/main.gd`, `CitySlice`, `CityRunLifecycle`, `RunSummarySnapshot`, `PlayerCombatProfileStore`, `LeaderboardBridge`. Main alone selects/reconstructs stages; gameplay finalizes each run once. Validate definitions and catalog references before entering gameplay. Tests cover synthetic second registration, invalid content, duplicate terminal events, score bounds, metadata and malformed persistence.
2. **Navigation and developer tooling:** new `scripts/ui/pause_menu.gd`, shared modal pause/focus lease, Main integration, `RuntimeTweakPanel`, launcher and category metadata. A nested panel never resumes a paused game or leaves stale input. Buttons remain reachable by keyboard/gamepad/touch. Only debug builds expose tuning; release ignores saved debug deltas.
3. **Onboarding and presentation:** versioned tutorial preferences, replay route, input-specific copy, safe layout; GPT Image 2 pause art; inexpensive vignette and reduced motion; Audio descriptors and UI cues. No gameplay retuning or new acts.
4. **Localization:** English/Chinese keys for every new surface, loader strings and runtime errors; share locale selection between loader and Godot; maintain placeholder parity and bundled fonts.
5. **Acceptance and delivery:** run focused tests while implementing, then full retained/new suites, deterministic victory and defeat scenarios, native captures, isolated release-pack boot and a clean-cache CDN restore/export. ## Policy and scope decisions

- **Act count:** the user's Act-1-only requirement takes precedence over the optional second authored stage. A synthetic second definition proves extensibility without shipping Act 2.
- **Supplied media:** preserve the original game and title assets as explicitly requested. Generate only newly required static art using GPT Image 2. Keep source soundtrack/cues, with their provenance, rather than synthesize replacement placeholders.
- **Local standings:** current shared rules require local-only standings by default. The supplied global bridge is disabled and its tabs are unreachable; reference fixtures test its parsers without enabling runtime networking. A future explicit opt-in must implement the full host/database/API integration, not merely flip a flag.
- **Documentation integration:** the original read-first external-link requirement is superseded in this repository by the committed shared-guide generator. All shared sections precede scroller instructions in the delivered README/Skill, and generator checks enforce that ordering without a now-deleted file link.
- **Debug tuning:** the shared README requires release builds to keep developer tuning hidden. The persistent-button requirement applies to all debug/owner screens; this does not authorize exposing tuning in production.
- **Browser acceptance:** the shared verification rule says, “Do not run an Agent browser self-test.” Automated acceptance uses Godot-native captures and exported-pack execution. Final browser acceptance (audio unlock, controls, Web layout, persistence and sustained play) remains a user step after delivery.
- **Payload:** the final 12.57 MiB Act 1 PCK exceeds the shared approximate 5 MB preference but remains within its documented 16 MiB regression budget. Preserve required original media and report actual size; do not silently degrade source animation or remove content to chase a suggested size.

- **Source scope:** later acts, automatic chaos hazards and the original terminal-shop economy remain intentionally unchanged. Transactional guarantees for hypothetical future upgrade/shop implementations are not claimed. The original art/title/music exceptions follow the user's supplied-game preservation request.
